## Quick Start (Local Development)

```bash
# 1. Add your OpenAI API key
cp .env.example .env
# Edit .env: OPENAI_API_KEY=sk-your-key

# 2. Build and run
docker compose up --build
```

## Local Access

- **Frontend:** http://localhost:3092
- **Backend API:** http://localhost:2937

## Features

- 💬 Real-time AI chat with GPT-3.5/GPT-4o
- 🖼️ Image upload & analysis (multi-modal)
- 📜 Cursor-based pagination with infinite scroll
- ⚡ Redis caching for performance
- 🛡️ Rate limiting protection
